# Sign-in issues

**Tags:** login, sign in, Google, Apple, password, account

**When it matches:** Cannot sign in or wrong account.

**Reply skeleton:**

Thanks for writing.

Try the same provider you used at setup (Google, Apple, or email). If Google
shows an unfamiliar project name on the consent screen, cancel and try again
after updating the app.

Signing out clears local bills for that account on the device — sign-in won’t
restore cloud bills in v1 (there isn’t a bill sync server yet).

If you’re stuck on a blank consent page, tell us which button you used
(Google / Apple / email) and your iOS version.

— Ben Support
